# HMS Commander MCP

A constrained, read-only text information server built on public HMS Commander APIs and the official Model Context Protocol Python SDK.

The initial implementation will be proposed in a draft pull request. It is not yet a published package. Project queries belong in bounded informational subagents; spatial, gridded, binary, modifying and execution workflows use the public Python libraries outside MCP.

HMS Commander is an independent open source project that complements HEC's work and is not affiliated with HEC or USACE.
